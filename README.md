# Developer Portfolio - Muthu Abishek M

A modern, responsive full-stack developer portfolio built with React.js, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Tech Stack
- **Frontend**: React.js, Tailwind CSS, Framer Motion, Lucide Icons
- **Build Tool**: Vite

## 🛠️ Features
- Interactive Hero section with dynamic role switching
- About section & skills showcase
- Interactive Project showcases with detail modals
- Experience & Internship timeline
- Contact section & social links
- Modern UI with smooth animations & glassmorphism aesthetics

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/abishek16-coder/devportfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
